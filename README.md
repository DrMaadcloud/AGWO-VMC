# AGWO-VMC: reproducibility package

Code, seed plans, raw run logs and analysis scripts for the article

> *A Grey Wolf Optimizer with Host-Evacuation Local Search for Energy-Aware Virtual Machine Consolidation in Green Data Centers*

Every table and figure in the article and in its supplementary material is generated by the scripts below from the raw run logs in `data/`.

## Contents

| Folder | Contents |
|---|---|
| `simulator/` | Java 17 Maven project (CloudSim Plus 8.5.7). Package `org.agwovmc.sim` holds the simulation driver, scenarios, power model and PABFD baseline. Package `org.agwovmc.revision` holds AGWO-VMC, the comparison optimizers (GWO, I-GWO, mGWO, chaotic GWO, PSO, GA, HHO, LAA, GSO, OOA, DRA, NSGA-II), the local search, the softmax decoder and the seed plan. |
| `data/results_v2/` | Main campaign: `runs.csv` (3,955 runs: main comparison, ablation, sensitivity, λ × γ grid, weight profiles, random weights, scalability) and `iters/` (per-iteration logs used for the convergence and diversity figures). |
| `data/results_v3/` | Second campaign: `runs.csv` (1,440 runs: NSGA-II, LAA, GSO, OOA and DRA, with and without local search), `fronts/` (NSGA-II fronts and AGWO-VMC solutions per logged cycle) and `iters/`. |
| `analysis/` | Python scripts that turn the run logs into the tables, statistics and figures. |

## Re-running the simulations

Requirements: JDK 17 or later and Maven 3.9.

```
cd simulator
mvn -q package
mvn -q exec:java -Dexec.args="v2"            # main campaign, written to results_v2/
mvn -q exec:java                              # second campaign, written to results_v3/
mvn -q exec:java -Dexec.args="v2 main,scal"   # only the listed experiments
```

Experiment names: `main`, `ablation`, `sens`, `lamgam`, `weights_named`, `weights_random`, `scal` (main campaign) and `main3` (second campaign). The driver uses all but one CPU thread and skips runs that are already in `runs.csv`, so an interrupted campaign can be resumed. All seeds are fixed in the code (`SeedPlan`), so a re-run reproduces the logged values.

## Re-running the analysis

Requirements: Python 3.11 or later and the packages in `analysis/requirements.txt` (`pip install -r analysis/requirements.txt`).

```
cd analysis
python analyze_v2.py ../data/results_v2 out          # main-campaign tables and statistics, Figs. 3 and 6-10, results_v2.json
python ms_figs.py out                                 # Figs. 4 and 5
python analyze_v3.py ../data/results_v2 ../data/results_v3 out   # NSGA-II and recent metaheuristics, Fig. S3
python supp_data.py ../data/results_v2 out           # supplementary tables
python fig1.py out                                    # Fig. 1 (architecture)
python fig2.py out                                    # Fig. 2 (control coefficient)
```

Figures from `analyze_v2.py` and `ms_figs.py` are written at 300 dpi by default; set the environment variable `FIGDPI=600` for print resolution. `fig1.py` and `fig2.py` always write 600 dpi, and Fig. S3 from `analyze_v3.py` is written at 300 dpi.
